# Ιστορικό αλλαγών

Καταγραφή ανά έκδοση TransferBook+. Για συνοπτική παρουσίαση προς πελάτες δείτε [Σημειώσεις εκδόσεων](/el/release-notes/).

**Στιγμιότυπο: v0.7.26 · 2026-11-27 (UTC).**

Οι ημερομηνίες είναι ημερομηνίες δημοσίευσης GitHub ή, όταν δεν υπάρχει χωριστή καταγραφή έκδοσης, ημερομηνίες υπογεγραμμένης ετικέτας. Οι πέντε εγγραφές μόνο από ετικέτα έχουν περιορισμένη τεκμηρίωση. Οι αναφορές CI προέρχονται από τις καταγραφές εκδόσεων και δεν αποτελούν νέα εκτέλεση δοκιμών. Η δημοσίευση δεν αποδεικνύει εγκατάσταση, αποδοχή λειτουργίας ή εμπορική διαθεσιμότητα. Οι κατηγορίες που δεν τεκμηριώνονται παραλείπονται.
