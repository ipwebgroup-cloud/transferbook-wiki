# Πρώτα βήματα

Καλώς ήρθατε στο TransferBook+, την πλατφόρμα διαχείρισης μεταφορών, κρατήσεων, αναθέσεων και εμπορικών λειτουργιών.

## Προετοιμασία του χώρου εργασίας

1. Επιβεβαιώστε την εγκατεστημένη έκδοση λογισμικού και τα δικαιώματα πρόσβασης.
2. Ελέγξτε την περιοχή λειτουργίας, τις διαθέσιμες κατηγορίες οχημάτων και τις καταχωρισμένες τοποθεσίες.
3. Για εκπαίδευση χρησιμοποιήστε εγκεκριμένο δοκιμαστικό περιβάλλον και συνθετικά στοιχεία επιβατών.

Οι διαθέσιμες λειτουργίες εξαρτώνται από την εγκατεστημένη έκδοση, τα δικαιώματα και τις ενεργές διασυνδέσεις. Η τοπική τεκμηρίωση αποτελεί προσχέδιο προς έλεγχο.
