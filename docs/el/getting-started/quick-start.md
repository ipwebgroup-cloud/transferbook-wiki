# Γρήγορη εκκίνηση διαχειριστή

::: info Έκδοση αναφοράς
Οδηγίες βάσει v0.7.26. Επιβεβαιώστε εγκατεστημένη έκδοση, δικαιώματα και εγκεκριμένο εύρος. Η εκπαίδευση χρησιμοποιεί εγκεκριμένα συνθετικά δεδομένα· δεν εγκρίνεται εμπορική ενεργοποίηση.
:::

## Πρώτη συνεδρία διαχειριστή

1. Λάβετε εγκεκριμένη διεύθυνση εγκατάστασης και ατομικά διαπιστευτήρια από εξουσιοδοτημένο διαχειριστή. Ελέγξτε HTTPS, επιλογή εταιρείας και ρόλο.
2. Εξετάστε [ένταξη εταιρείας](/el/getting-started/company-onboarding.html). Ολοκληρώστε νομική ταυτότητα, αγορές, τοπικές ζώνες ώρας, κατάλογο, στόλο και εγκεκριμένη τιμολόγηση.
3. Ζητήστε δημιουργία κάθε λογαριασμού στο backend· μην μοιράζεστε διαπιστευτήρια διαχειριστή. Συνδέστε πραγματικούς λογαριασμούς οδηγών με εξουσιοδοτημένες εγγραφές και δοκιμάστε περιορισμένη πρόσβαση.
4. Εξετάστε καταγραφή πληρωμών, κανάλια, πρότυπα και εταιρική εικόνα. Μην ενεργοποιείτε δημόσιο κανάλι ή πάροχο μόνο για να συμπληρωθεί η λίστα.
5. Σε εγκεκριμένο συνθετικό περιβάλλον δημιουργήστε [πρώτη κράτηση](/el/getting-started/first-reservation.html), δοκιμάστε ανάθεση, πρόσβαση οδηγού και συμφωνία πληρωμών. Καταγράψτε αποτυχίες πριν προχωρήσετε.
6. Εξετάστε [αποδοχή έναρξης](/el/getting-started/go-live-checklist.html) με επιχειρησιακούς και τεχνικούς υπευθύνους. Λάβετε έγκριση συγκεκριμένου εύρους· μη αποδεκτές λειτουργίες παραμένουν ανενεργές.

## Καθημερινή διαχείριση

Ελέγξτε αλλαγές πρόσβασης, αποτυχίες, προσεχείς αναθέσεις, οικονομικές εξαιρέσεις και ετοιμότητα παρόχων. Επιβεβαιώστε έκδοση και δείτε [Σημειώσεις εκδόσεων](/el/release-notes/) πριν από ενημέρωση. Χρησιμοποιήστε [Διαχείριση ενημερώσεων](/el/plus/software-update-manager.html)· δεν υπονοείται αυτόματη έγκριση εμπορικών αναβαθμίσεων.
