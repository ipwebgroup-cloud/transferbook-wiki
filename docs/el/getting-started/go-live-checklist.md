# Αποδοχή εμπορικής έναρξης

::: info Έκδοση αναφοράς
Οδηγίες βάσει v0.7.26. Επιβεβαιώστε εγκατεστημένη έκδοση, δικαιώματα και εγκεκριμένο εύρος. Η εκπαίδευση χρησιμοποιεί εγκεκριμένα συνθετικά δεδομένα· δεν εγκρίνεται εμπορική ενεργοποίηση.
:::

## Καταγραφή αποδοχής

Καταγράψτε εταιρεία, εγκεκριμένο περιβάλλον, ακριβή έκδοση, ημερομηνία, επιχειρησιακό και τεχνικό υπεύθυνο και εύρος. Η λίστα είναι χειροκίνητη· επιλογή σε τεκμηρίωση δεν ενεργοποιεί λειτουργία.

| Έλεγχος | Απαιτούμενα τεκμήρια |
| --- | --- |
| Εγκατάσταση | Εγκεκριμένη έκδοση και υπογραφή, HTTPS, υγεία, migrations και δοκιμασμένη επαναφορά |
| Πρόσβαση | Πραγματικοί λογαριασμοί διαχειριστή, χειριστή, οδηγού και viewer· απομόνωση και απαγορευμένες ενέργειες |
| Εταιρικά δεδομένα | Εγκεκριμένη εταιρεία, αγορές, τοποθεσίες, στόλος, οδηγοί, φόροι και ναύλοι |
| Κρατήσεις | Τέσσερις τύποι υπηρεσιών όπου πωλούνται, μόνο τηλέφωνο, χειροκίνητη προσφορά, προστασία διπλοεγγραφών και συγκρούσεων |
| Αναθέσεις | Πλήρης διάρκεια, συντήρηση, ανεξάρτητα σκέλη και έλεγχος ειδοποιήσεων αφίξεων |
| Οικονομικά | Είσπραξη, φύλαξη και συμφωνία· αποδοχή παρόχου μόνο αν είναι ενεργός |
| Δημόσια πύλη | Απομόνωση domain/καναλιού, έγκυρες προσφορές, προστασία κατάχρησης και ρητή έγκριση λήψης |
| Μηνύματα και AI | Ιδιωτικότητα, συγκατάθεση, εξαίρεση, επαλήθευση παράδοσης, ανάληψη χειριστή και έγκριση παρόχου |
| GPS και κανονιστικά | Φυσική δοκιμή κινητού και ξεχωριστή ζωντανή έγκριση· sandbox δεν είναι συμμόρφωση |
| Λειτουργία | Εκπαίδευση, υποστήριξη, εναλλακτική σε συμβάν και έγκριση ιδιοκτήτη |

## Απόφαση

Χαρακτηρίστε κάθε έλεγχο επιτυχή, αποτυχημένο ή μη εφαρμόσιμο με τεκμήριο και υπεύθυνο. Αναβάλετε τις σχετικές ροές μέχρι αποδοχή. Υπογεγραμμένη έκδοση, πλήρης λίστα ένταξης, επιτυχές CI ή έλεγχος τεκμηρίωσης δεν αποδεικνύουν γενική εμπορική ετοιμότητα.

Στη v0.7.26 εκκρεμούν αυτόματες εξωτερικές αφίξεις, προγραμματισμός παρασκηνίου, πλήρης επιβολή ορίων, αδειοδοτημένοι οδικοί χάρτες και φυσικός έλεγχος GPS. Εξωτερικοί πάροχοι και δημόσια λήψη παραμένουν ανενεργοί μέχρι έγκριση. Ζωντανές κανονιστικές υποβολές απαιτούν χωριστή αποδοχή. Δεν επιβεβαιώνεται παραγωγική εγκατάσταση πελάτη.

Δείτε [Εγκατάσταση](/el/installation/), [Αντίγραφα και ανάκτηση](/el/getting-started/backup-recovery.html) και [API τρίτων](/el/integrations/third-party-api-setup.html).
