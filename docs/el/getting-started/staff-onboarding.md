# Λίστα ένταξης προσωπικού και οδηγών

::: info Έκδοση αναφοράς
Οδηγίες βάσει v0.7.26. Επιβεβαιώστε εγκατεστημένη έκδοση, δικαιώματα και εγκεκριμένο εύρος. Η εκπαίδευση χρησιμοποιεί εγκεκριμένα συνθετικά δεδομένα· δεν εγκρίνεται εμπορική ενεργοποίηση.
:::

## Πριν την πρώτη βάρδια

- [ ] Επιβεβαίωση εγκεκριμένης ταυτότητας, καθηκόντων, εταιρείας και πρόσβασης.
- [ ] Αίτημα ατομικού λογαριασμού backend και ελάχιστου ρόλου από εξουσιοδοτημένο διαχειριστή.
- [ ] Για οδηγό: δημιουργία ή έλεγχος εγγραφής, εγκεκριμένου οχήματος/βάρδιας και σύνδεσης λογαριασμού.
- [ ] Ασφαλής παράδοση διαπιστευτηρίων· ισχυροί μοναδικοί κωδικοί.
- [ ] Δοκιμή πραγματικού ρόλου, εταιρικού ορίου, αποσύνδεσης και απαγορευμένων ενεργειών με συνθετικά δεδομένα.
- [ ] Δοκιμή κινητού browser, σύνδεσης, ορατότητας ανάθεσης, ανεξάρτητων σκελών και ενημέρωσης άφιξης όπου διατίθεται.
- [ ] Ενημέρωση για ιδιωτικότητα επιβατών, είσπραξη και φυσική παράδοση μετρητών.
- [ ] Δοκιμή ρητής κοινοποίησης GPS εντός βάρδιας μόνο όπου εγκρίνεται· χωριστή αποδοχή φυσικής συσκευής.
- [ ] Παροχή επαφών κλιμάκωσης και υποστήριξης· καταγραφή αποδοχής εκπαίδευσης.

Η λίστα είναι χειροκίνητο βοήθημα, όχι φόρμα δημιουργίας λογαριασμού ή αυτόματα αποθηκευμένη έγκριση. Δημόσια αίτηση εργασίας δεν δημιουργεί λογαριασμό. Σε αποχώρηση ζητήστε ανάκληση πρόσβασης και συνεδριών στο backend, επαληθεύστε απόρριψη και διατηρήστε επιχειρησιακές εγγραφές.

Δείτε [Προσωπικό](/el/plus/staff-administration.html), [Χώρος οδηγού](/el/plus/chauffeur-workspace.html) και [Ασφάλεια](/el/security-privacy/).
