# Ιστοσελίδες και πρότυπα

::: info Έκδοση αναφοράς — προσχέδιο βάσει κώδικα
TransferBook+ v0.7.9. Η διαθεσιμότητα εξαρτάται από την εγκατεστημένη έκδοση, τα δικαιώματα και τις ρυθμίσεις. Ο οδηγός δεν επιβεβαιώνει δημόσια δημοσίευση.
:::

## Αλλαγές στις v0.7.10 και v0.7.11
Οι αρχικοί οδηγοί v0.7.9 παραμένουν η βάση. Οι ενότητες ανά έκδοση περιγράφουν μεταγενέστερες εκδόσεις staging που ελέγχθηκαν βάσει κώδικα, όχι επαληθευμένες εγκαταστάσεις.

- v0.7.10: βελτιωμένος [επεξεργαστής](./studio-overview.md), [γλωσσική κάλυψη](./design-and-localization.md), [ανάκτηση προσχεδίων](./draft-storage.md) και [εισαγωγή πακέτων](./portable-packages.md).
- v0.7.11: χωριστή, περιορισμένη [ροή φιλοξενίας και διαχείρισης ιστοσελίδας](./publication-controls.md), απενεργοποιημένη από προεπιλογή. Οι γενικοί κανόνες δημοσίευσης του Template Manager παραμένουν διακριτοί.

Ελέγξτε τις [σημειώσεις εκδόσεων](/el/release-notes/) πριν ακολουθήσετε οδηγίες ανά έκδοση.
