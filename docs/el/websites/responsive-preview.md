# Προεπισκόπηση ανά συσκευή

::: info Έκδοση αναφοράς — προσχέδιο βάσει κώδικα
TransferBook+ v0.7.9. Η διαθεσιμότητα εξαρτάται από την εγκατεστημένη έκδοση, τα δικαιώματα και τις ρυθμίσεις. Ο οδηγός δεν επιβεβαιώνει δημόσια δημοσίευση.
:::

## Σκοπός
Ελέγξτε το προσχέδιο στις τέσσερις διαστάσεις του Website Studio. Ο έλεγχος δεν δημοσιεύει ιστοσελίδα ούτε δημιουργεί πραγματική κράτηση.

| Λειτουργία | Πλάτος αναφοράς |
|---|---|
| Desktop | 100% του καμβά |
| Tablet | 768 px |
| Mobile | 390 px |
| Narrow Mobile | 320 px |

## Έλεγχος
1. Ανοίξτε τη σελίδα στο Desktop και ελέγξτε κεφαλίδα, περιεχόμενο και υποσέλιδο.
2. Μεταβείτε σε Tablet, Mobile και Narrow Mobile.
3. Ελέγξτε αναδίπλωση κειμένου, ορατότητα κουμπιών, πλοήγηση και οριζόντια υπερχείλιση.
4. Ελέγξτε φόρμες κράτησης και διατάξεις εικόνων: στο κινητό πρέπει να στοιβάζονται κατακόρυφα.
5. Ελέγξτε τους κανόνες ορατότητας ανά συσκευή ώστε να μη λείπουν σημαντικές πληροφορίες.

## Αποτέλεσμα και αντιμετώπιση προβλημάτων
Ο renderer προσαρμόζεται στο επιλεγμένο πλαίσιο προεπισκόπησης. Αν κόβεται κείμενο, διορθώστε αποστάσεις, περιεχόμενο ή παραλλαγή και επανελέγξτε. Απαιτείται επίσης έλεγχος σε πραγματικές συσκευές. Το email επιβάτη παραμένει προαιρετικό. Δείτε [σελίδες και ενότητες](./pages-and-sections.md).
