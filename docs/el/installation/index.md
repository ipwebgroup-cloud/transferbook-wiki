# Εγκατάσταση και ανάπτυξη

Ο οδηγός περιγράφει την προετοιμασία ενός εγκεκριμένου περιβάλλοντος TransferBook+, την ένταξη μιας επιχείρησης στην πλατφόρμα και την ασφαλή διαχείριση εκδόσεων. Συμπληρώνει τις [απαιτήσεις συστήματος](/el/system-requirements/).

Η αγγλική τεκμηρίωση είναι η πηγή αναφοράς. Η πλήρης ελληνική απόδοση θα ενταχθεί στην προγραμματισμένη επικαιροποίηση μεταφράσεων.

- Η πρόσβαση μέσω προγράμματος περιήγησης δεν απαιτεί τοπική εγκατάσταση βάσης δεδομένων ή περιβάλλοντος εκτέλεσης.
- Η διαχειριζόμενη ή αποκλειστική φιλοξενία και η εγκατάσταση σε υποδομή του πελάτη προϋποθέτουν εγκεκριμένη διάθεση και συμφωνημένους όρους υποστήριξης. Ο οδηγός δεν αποτελεί προσφορά αυτοδιαχειριζόμενης εγκατάστασης.
- Πριν από την έναρξη λειτουργίας, επιβεβαιώστε την έκδοση, τα δικαιώματα, τις περιοχές, τον στόλο, τους οδηγούς, την τιμολόγηση και τα εγκεκριμένα κανάλια κρατήσεων.
- Διαχωρίστε τα περιβάλλοντα παραγωγής, δοκιμών και επίδειξης. Χρησιμοποιήστε συνθετικά δεδομένα στις δοκιμές.
- Πριν από κάθε αναβάθμιση, ελέγξτε τα αντίγραφα ασφαλείας, τη δυνατότητα ανάκτησης, τις αλλαγές στη βάση δεδομένων και τα κριτήρια αποδοχής.
- Ελέγξτε τις κρατήσεις χωρίς υποχρεωτικό email επιβάτη, τις αναθέσεις και τις ενεργές διασυνδέσεις πριν δεχθείτε πραγματικές κρατήσεις.
