# Απαιτήσεις συστήματος

Το TransferBook+ είναι πλατφόρμα διαχείρισης μεταφορών μέσω προγράμματος περιήγησης. Οι παρακάτω απαιτήσεις βοηθούν τους πελάτες να προετοιμάσουν τις συσκευές τους και τις τεχνικές ομάδες να αξιολογήσουν τη φιλοξενία.

::: warning Συμβατότητα και χωρητικότητα
Πρόκειται για συστάσεις σχεδιασμού, όχι πιστοποιημένες ελάχιστες προδιαγραφές ή εγγύηση εμπορικής διαθεσιμότητας. Η έκδοση πηγαίου κώδικα αναφοράς αυτού του οδηγού είναι v0.7.13. Η πραγματική υποστήριξη εξαρτάται από την αποδεκτή εγκατάσταση, τις ενεργές λειτουργίες, τα δικαιώματα και τις δοκιμές συμβατότητας.
:::

## Συσκευές και προγράμματα περιήγησης

| Στοιχείο | Προτεινόμενη βάση σχεδιασμού |
| --- | --- |
| Λειτουργικό υπολογιστή | Υποστηριζόμενη από τον κατασκευαστή έκδοση Windows, macOS ή Linux |
| Λειτουργικό κινητού | Υποστηριζόμενη έκδοση Android ή iOS |
| Πρόγραμμα περιήγησης | Τρέχουσα σταθερή έκδοση Chrome, Edge, Firefox ή Safari, ανά συσκευή |
| Σταθμός γραφείου | Σύγχρονος επεξεργαστής δύο πυρήνων ή καλύτερος, 8 GB RAM |
| Οθόνη χειριστή | 1920 × 1080 ή μεγαλύτερη· συνιστώνται πληκτρολόγιο και ποντίκι |
| Κινητή συσκευή | Οθόνη αφής, υποστηριζόμενος browser, αξιόπιστα δεδομένα κινητής ή Wi-Fi |
| Συνδεσιμότητα | Αξιόπιστη ευρυζωνική ή κινητή σύνδεση· συνιστάται εφεδρική σύνδεση για αναθέσεις |
| Ρυθμίσεις browser | Ενεργή JavaScript και απαραίτητα cookies πρώτου μέρους· πρόσβαση HTTPS |

Δεν απαιτείται εγκατάσταση εγγενούς εφαρμογής για πρόσβαση μέσω browser. Οι συνδυασμοί συσκευών και browser αποτελούν υποψήφιες επιλογές προς έλεγχο, όχι πιστοποιημένες πλατφόρμες. Μην θεωρείτε δεδομένη τη λειτουργία offline, παρακολούθηση στο παρασκήνιο, push ειδοποιήσεις ή εγγενή εφαρμογή.

## Απαιτήσεις ανά ρόλο

| Ρόλος | Προετοιμασία |
| --- | --- |
| Διαχειριστής εταιρείας | Υπολογιστής, εξουσιοδοτημένος λογαριασμός, πρόσβαση στις ρυθμίσεις εταιρείας |
| Χειριστής αναθέσεων | Υπολογιστής με επαρκή οθόνη, αξιόπιστο διαδίκτυο, δικαιώματα και ρυθμισμένα επιχειρησιακά δεδομένα |
| Οδηγός | Φορτισμένη κινητή συσκευή, αξιόπιστη σύνδεση και λογαριασμός· δικαιώματα τοποθεσίας μόνο για ενεργή λειτουργία που τα απαιτεί |
| Εμπορικός συνεργάτης | Υποστηριζόμενος browser και εξουσιοδοτημένη πρόσβαση συνεργάτη, όπου διατίθεται |
| Επιβάτης | Συσκευή με browser και ενεργό δημόσιο κανάλι κρατήσεων· δεν προϋποτίθεται λογαριασμός χειριστή |

Το email επιβάτη δεν είναι υποχρεωτικό για γρήγορες κρατήσεις. Χρησιμοποιήστε επιτρεπόμενο τρόπο επικοινωνίας χωρίς επινοημένες διευθύνσεις. Δείτε [κράτηση μόνο με τηλέφωνο](/el/tutorials/phone-only-booking.html) και [στοιχεία επιβάτη](/el/plus/passenger-information.html).

## Δίκτυο και ασφάλεια

- Χρησιμοποιήστε HTTPS στην εξουσιοδοτημένη εγκατάσταση και ενημερωμένο λειτουργικό και browser.
- Χρησιμοποιήστε ατομικούς λογαριασμούς και δικαιώματα βάσει ρόλου. Μην μοιράζεστε διαπιστευτήρια.
- Επιτρέψτε πρόσβαση HTTPS στην εγκεκριμένη εφαρμογή και μόνο στα ρητά ενεργοποιημένα endpoints τρίτων. Μην απενεργοποιείτε firewall ή επαλήθευση πιστοποιητικών.
- Κλειδώνετε την οθόνη και μην αποθηκεύετε στοιχεία επιβατών σε μη διαχειριζόμενες συσκευές.
- Ελέγχετε ώρα συστήματος, ζώνη ώρας και ρυθμίσεις browser. Σε διακοπή υποβολής, εξακριβώστε αν υπάρχει ήδη κράτηση ή πληρωμή πριν από επανάληψη.
- Χρησιμοποιήστε μόνο συνθετικά στοιχεία επιβατών σε εγκεκριμένα περιβάλλοντα εκπαίδευσης ή staging.

Δείτε [ταυτοποίηση](/el/developers/authentication.html), [ρόλους και δικαιώματα](/el/developers/permissions.html) και [σφάλματα πρόσβασης](/el/help/access-and-session.html).

## Απαιτήσεις διακομιστή και φιλοξενίας

Η ενότητα αφορά τεχνικές ομάδες και παρόχους φιλοξενίας, όχι απλούς πελάτες. Η διαχειριζόμενη εγκατάσταση δεν απαιτεί Node.js ή PostgreSQL στον υπολογιστή πελάτη. Η αποκλειστική ή αυτοδιαχειριζόμενη φιλοξενία εξαρτάται από χωριστή έγκριση, υποστηριζόμενα πακέτα και ετοιμότητα. Δεν αποτελεί εμπορική προσφορά self-hosting.

| Στοιχείο | Προτεινόμενη βάση αξιολόγησης |
| --- | --- |
| Λειτουργικό | Υποστηριζόμενο Linux 64 bit |
| CPU | 4 vCPU |
| RAM | 8 GB |
| Αποθήκευση | 80 GB SSD/NVMe με παρακολούθηση χωρητικότητας |
| Runtime | Node.js 24 LTS ως αναφορά· επιβεβαιώστε την ακριβή υποστηριζόμενη έκδοση |
| Βάση | PostgreSQL 16 ως αναφορά· επιβεβαιώστε έκδοση και migrations |
| Reverse proxy | Apache ή NGINX με τερματισμό TLS |
| Διαχείριση υπηρεσίας | Επιτηρούμενη διεργασία με ελέγχους υγείας |
| Email και εξωτερικές υπηρεσίες | Εγκεκριμένα διαπιστευτήρια και σύνδεση μόνο για ενεργές διασυνδέσεις |
| Αντίγραφα | Αυτοματοποιημένα, προστατευμένα αντίγραφα βάσης και εφαρμογής· δοκιμασμένη επαναφορά |

Ο ελεγμένος κώδικας χρησιμοποιεί React/TypeScript, API Node.js/Express και PostgreSQL client. Οι εκτιμήσεις υλικού είναι αρχικές βάσεις. Δεν καθορίζεται εγγύηση χωρητικότητας, ταυτόχρονης χρήσης, καθυστέρησης ή διαθεσιμότητας.

### Προϋποθέσεις εγκατάστασης

- Οδηγίες build και migrations ανά έκδοση, ελεγμένα πακέτα και τεκμηριωμένο σχέδιο επαναφοράς.
- Λογαριασμοί υπηρεσίας και βάσης με ελάχιστα δικαιώματα· μυστικά και κλειδιά υπογραφής εκτός δημόσιου περιεχομένου και Git.
- Έγκυρα DNS και TLS, σωστό reverse proxy, περιορισμένη πρόσβαση βάσης, έλεγχοι υγείας και καταγραφή.
- Ανεξάρτητα περιβάλλοντα παραγωγής, staging και demo. Ποτέ staging ως σιωπηρός στόχος παραγωγής.
- Αντίγραφα με διατήρηση και δοκιμές επαναφοράς· παρακολούθηση σφαλμάτων, δίσκου, βάσης και λήξης πιστοποιητικών.
- Χωριστή έγκριση και ολοκληρωμένες δοκιμές πληρωμών, ειδοποιήσεων, εξωτερικών αναθέσεων, χαρτών ή AI πριν την ενεργοποίηση.

## Αποδοχή συμβατότητας και χωρητικότητας

Πριν δημοσιευθούν πιστοποιημένες απαιτήσεις, ελέγξτε την ακριβή έκδοση στις προβλεπόμενες συσκευές και browser. Δοκιμάστε σύνδεση και λήξη συνεδρίας, κρατήσεις (με προαιρετικό email επιβάτη), πρόγραμμα, αναθέσεις, περιορισμούς ρόλων, κινητή ροή οδηγού, επαναφορά μετά από διακοπή δικτύου και ενεργές διασυνδέσεις. Μετρήστε χρήση πόρων και χρόνους απόκρισης σε αντιπροσωπευτικό φόρτο αιχμής και δοκιμάστε επαναφορά αντιγράφων. Καταγράψτε εκδόσεις, αποτελέσματα και περιορισμούς.

Δείτε [ετοιμότητα διασυνδέσεων](/el/integrations/activation-and-channels.html) και [σημειώσεις εκδόσεων](/el/release-notes/).
