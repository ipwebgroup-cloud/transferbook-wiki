# Απαιτήσεις συστήματος

Το TransferBook+ λειτουργεί μέσω προγράμματος περιήγησης. Οι παρακάτω πληροφορίες αποτελούν συστάσεις προετοιμασίας και όχι πιστοποιημένες ελάχιστες απαιτήσεις.

Η αγγλική τεκμηρίωση είναι η πηγή αναφοράς. Η πλήρης ελληνική απόδοση θα ενταχθεί στην προγραμματισμένη επικαιροποίηση μεταφράσεων.

- Χρησιμοποιήστε ενημερωμένο λειτουργικό σύστημα και πρόγραμμα περιήγησης, ασφαλή σύνδεση HTTPS και σταθερή πρόσβαση στο διαδίκτυο.
- Για αναθέσεις και διαχείριση συνιστάται υπολογιστής με μεγάλη οθόνη. Για οδηγούς, κινητή συσκευή με αξιόπιστη σύνδεση.
- Δεν απαιτείται τοπική εγκατάσταση λογισμικού για πρόσβαση μέσω προγράμματος περιήγησης.
- Οι προτεινόμενες προδιαγραφές φιλοξενίας και η συμβατότητα συσκευών χρειάζονται δοκιμές πριν πιστοποιηθούν.
