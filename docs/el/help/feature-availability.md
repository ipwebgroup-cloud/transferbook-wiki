# Πίνακας διαθεσιμότητας λειτουργιών

::: info Έκδοση αναφοράς
Αναφορά v0.7.26, όχι έλεγχος ζωντανής εγκατάστασης ή έγκριση εμπορικής λειτουργίας. Ελέγξτε έκδοση, δικαιώματα, ρυθμίσεις και αποδοχή.
:::

## Ερμηνεία καταστάσεων

- **Υλοποιημένο:** περιλαμβάνεται στην έκδοση ή στον ελεγμένο κώδικα· απαιτεί αποδοχή της εγκατάστασης.
- **Ρυθμίσιμο / βάσεις:** υπάρχουν διαδρομές ρύθμισης ή τμήματα διασύνδεσης, όχι απόδειξη ζωντανής σύνδεσης.
- **Sandbox:** δοκιμαστική λειτουργία, όχι επίσημη υποβολή.
- **Εκκρεμεί / ανενεργό:** δεν επιβεβαιώνεται διαθέσιμη ζωντανή λειτουργία.

Εξωτερικοί πάροχοι και δημόσια λήψη παραμένουν απενεργοποιημένοι μέχρι έγκριση. Ο πίνακας αφορά TransferBook+, όχι άλλες εκδόσεις ή εμπορικά πακέτα.
