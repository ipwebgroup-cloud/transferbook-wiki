# Γλωσσάρι όρων

::: info Έκδοση αναφοράς
Αναφορά v0.7.26, όχι έλεγχος ζωντανής εγκατάστασης ή έγκριση εμπορικής λειτουργίας. Ελέγξτε έκδοση, δικαιώματα, ρυθμίσεις και αποδοχή.
:::

Οι όροι εξηγούν τη σημασία τους στην επιχειρησιακή τεκμηρίωση, όχι νομικούς ή λογιστικούς ορισμούς.

| Όρος | Σημασία |
| --- | --- |
| Εταιρικός χώρος (tenant) | Το όριο δεδομένων και εξουσιοδότησης ανά εταιρεία. |
| Αγορά / περιοχή λειτουργίας | Ρυθμισμένη περιοχή εξυπηρέτησης με επιχειρησιακές ρυθμίσεις. |
| Κατάλογος τοποθεσιών | Εγκεκριμένα σημεία αναφοράς παραλαβής και αποβίβασης. |
| Κανάλι κρατήσεων | Ρυθμισμένη προέλευση κρατήσεων· ενεργή ένδειξη δεν εγκρίνει δημόσια λήψη. |
| Κράτηση | Αποθηκευμένο αίτημα και κύκλος ζωής υπηρεσίας, όχι απαραίτητα εξοφλημένο ή ανατεθειμένο. |
| Προσφορά | Πρόταση τιμής υπό κανόνες και έλεγχο. |
| Επαληθευμένος ναύλος | Τιμή επαληθευμένη από κανόνες backend· έλλειψη επαλήθευσης απαιτεί έλεγχο. |
| Χειροκίνητη προσφορά | Τιμή ελεγμένη από χειριστή όταν δεν υπάρχει αυτόματος έγκυρος ναύλος. |
| Σκέλος διαδρομής | Ανεξάρτητο τμήμα μετάβασης ή επιστροφής. |
| Ανάθεση (dispatch) | Εξουσιοδοτημένη διάθεση πόρων σε κράτηση ή σκέλος. |
| Χρονικό περιθώριο ανάθεσης | Ρυθμισμένο περιθώριο προγραμματισμού· όχι εγγύηση διαθεσιμότητας. |
| Κατηγορία οχήματος | Κατηγορία υπηρεσίας και αναφορά χωρητικότητας/τιμής, διαφορετική από φυσικό όχημα. |
| Κατάλογος οδηγών | Επιχειρησιακές εγγραφές οδηγών, χωριστές από λογαριασμούς σύνδεσης. |
| Εταιρική συμμετοχή / RBAC | Συμμετοχή και έλεγχος πρόσβασης βάσει ρόλου που ορίζουν επιτρεπόμενες ενέργειες. |
| Άδεια κοινοποίησης GPS | Χρονικά περιορισμένη εξουσιοδότηση ρητής κοινοποίησης θέσης οδηγού. |
| Γεωγραφικό όριο (geofence) | Γεωγραφικό όριο αξιολόγησης θέσης σε σχέση με ρυθμισμένη περιοχή. |
| ETA | Εκτιμώμενος χρόνος άφιξης, όχι επιβεβαιωμένη άφιξη. |
| Παρατήρηση άφιξης | Χρονοσημασμένο τεκμήριο κατάστασης άφιξης. |
| Ειδοποίηση ανάθεσης | Πρόταση που απαιτεί έλεγχο πριν από επιχειρησιακή αλλαγή. |
| CRM | Εγγραφές σχέσεων πελατών και σύνδεση επαναλαμβανόμενων πελατών. |
| Συνεργάτης (affiliate) | Εμπορικός συνεργάτης με συμφωνημένη παραπομπή ή προμήθεια. |
| Υπεργολάβος | Εξωτερικός προμηθευτής μεταφοράς που αναλαμβάνει υπηρεσία ή σκέλος. |
| Υποχρέωση προμηθευτή | Καταγεγραμμένο εκκρεμές ποσό προς προμηθευτή, υπό συμφωνία. |
| Έγκριση πληρωμής | Έγκριση ή δέσμευση ποσού από πάροχο· όχι απαραίτητα είσπραξη ή διακανονισμός. |
| Είσπραξη μετρητών | Καταγραφή μετρητών που πραγματικά παραλήφθηκαν από επιβάτη. |
| Παράδοση μετρητών | Χωριστή επιβεβαίωση φυσικής μεταβίβασης φύλαξης στο γραφείο. |
| Συμφωνία συναλλαγών | Αντιστοίχιση καταγεγραμμένων συναλλαγών με επαληθευμένα τεκμήρια. |
| PSP | Πάροχος υπηρεσιών πληρωμών· ετοιμότητα διασύνδεσης δεν σημαίνει ενεργοποίηση. |
| Webhook | Callback παρόχου σε endpoint εφαρμογής· απαιτεί έλεγχο γνησιότητας και διπλών συμβάντων. |
| Ιδιοδυναμία (idempotency) | Προστασία από ανεπιθύμητα διπλά αποτελέσματα σε επανάληψη αιτήματος. |
| Ουρά αποστολής (outbox) | Μόνιμη ουρά εργασιών ειδοποιήσεων και κατάστασης επεξεργασίας. |
| Εξαίρεση (opt-out) | Καταγεγραμμένος περιορισμός αποστολής σε παραλήπτη ή κανάλι. |
| Ανάληψη από χειριστή | Κλιμάκωση συνομιλίας σε εξουσιοδοτημένο άνθρωπο. |
| Sandbox | Ελεγχόμενη δοκιμαστική λειτουργία ή περιβάλλον, όχι απόδειξη ζωντανής υπηρεσίας. |
| Ασφαλής αποκλεισμός (fail-closed) | Η ενέργεια παραμένει αποκλεισμένη όταν λείπει απαιτούμενη έγκριση ή ετοιμότητα. |
| Migration | Έκδοση αλλαγής σχήματος ή δεδομένων που απαιτεί έλεγχο ανά έκδοση. |
| Αποδοχή έκδοσης | Καταγεγραμμένο τεκμήριο ότι έκδοση και ροή πληρούν συμφωνημένους ελέγχους. |
| RPO / RTO | Συμφωνημένοι στόχοι σημείου και χρόνου ανάκτησης, που πρέπει να δοκιμάζονται. |
