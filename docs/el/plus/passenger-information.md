# Στοιχεία επιβάτη

::: info Έκδοση αναφοράς
Πηγαίος κώδικας TransferBook+ v0.7.9. Το παρόν είναι τοπικό προσχέδιο προς έλεγχο, όχι επιβεβαίωση διαθεσιμότητας στην παραγωγή. Ελέγξτε την εγκατεστημένη έκδοση και τα δικαιώματά σας.
:::

## Υποχρεωτικά και προαιρετικά πεδία
| Πεδίο | Απαίτηση |
| --- | --- |
| Guest Full Name | Υποχρεωτικό |
| Phone | Υποχρεωτικό |
| Email (Optional) | Προαιρετικό |
| Flight / Vessel Details | Όπου χρειάζεται |
| Tablet Sign Text | Όπου χρειάζεται |

## Κράτηση μόνο με τηλέφωνο
1. Καταχωρίστε το πραγματικό όνομα και τηλέφωνο επικοινωνίας του επιβάτη.
2. Αφήστε το email κενό αν δεν παρέχεται. Μην επινοείτε email.
3. Προσθέστε στοιχεία πτήσης ή πλοίου εφόσον χρειάζονται. Ελέγξτε το κείμενο της πινακίδας.
4. Αποθηκεύστε μέσω της [κανονικής διαδικασίας κράτησης](/el/plus/create-reservation).

## Αναμενόμενο αποτέλεσμα και προβλήματα
Η απουσία email από μόνη της δεν εμποδίζει τη δημιουργία κράτησης. Διορθώστε μη έγκυρα στοιχεία χωρίς να τα επινοείτε. Δεν μπορεί να θεωρηθεί δεδομένη αποστολή email χωρίς διεύθυνση. Χρησιμοποιήστε τα στοιχεία μόνο για εξουσιοδοτημένους λειτουργικούς σκοπούς.
