# Εγχειρίδιο χειριστή TransferBook+

::: info Έκδοση αναφοράς
Πηγαίος κώδικας TransferBook+ v0.7.9. Το παρόν είναι τοπικό προσχέδιο προς έλεγχο, όχι επιβεβαίωση διαθεσιμότητας στην παραγωγή. Ελέγξτε την εγκατεστημένη έκδοση και τα δικαιώματά σας.
:::

Η προηγμένη πλατφόρμα μεταφορών περιλαμβάνει κρατήσεις, αναθέσεις και τιμολόγηση. Οι οδηγοί καλύπτουν ροές χειριστή που έχουν ελεγχθεί στον κώδικα. Οι παρακάτω πρόσθετοι οδηγοί καλύπτουν επιπλέον ενότητες που έχουν ελεγχθεί στον κώδικα.
