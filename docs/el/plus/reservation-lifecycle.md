# Κύκλος ζωής κράτησης

::: info Έκδοση αναφοράς
Πηγαίος κώδικας TransferBook+ v0.7.9. Το παρόν είναι τοπικό προσχέδιο προς έλεγχο, όχι επιβεβαίωση διαθεσιμότητας στην παραγωγή. Ελέγξτε την εγκατεστημένη έκδοση και τα δικαιώματά σας.
:::

## Καταστάσεις
| Κατάσταση | Σημασία |
| --- | --- |
| New | Αρχική καταχώριση, πιθανή αναμονή προσφοράς ή ελέγχου |
| Confirmed | Επιβεβαιωμένη κράτηση |
| Assigned | Καταχωρισμένη ανάθεση οδηγού/οχήματος |
| In Transit | Διαδρομή σε εξέλιξη |
| Completed | Ολοκληρωμένη, τελική κατάσταση |
| Cancelled | Ακυρωμένη, τελική κατάσταση |

## Διαδικασία χειριστή
Ανοίξτε τη σωστή κράτηση και ελέγξτε την τρέχουσα κατάσταση. Χρησιμοποιήστε μόνο τις επιτρεπόμενες μεταβάσεις για τον ρόλο σας. Επιβεβαιώστε μόνο όταν πληρούνται οι απαιτήσεις τιμολόγησης και αποδοχής. Πριν από ακύρωση καταχωρίστε ουσιαστική αιτιολογία. Μετά την ολοκλήρωση ή ακύρωση επαληθεύστε την τελική κατάσταση χωρίς επαναφορά.

## Αναμενόμενο αποτέλεσμα και προβλήματα
Το σύστημα καταγράφει μεταβάσεις και ιστορικό ελέγχου. Εκκρεμής προσφορά εμποδίζει επιβεβαίωση και ανάθεση μέχρι την έγκριση τιμής. Οι τελικές κρατήσεις δεν επιδέχονται συνήθη επεξεργασία. Ελέγξτε τις προϋποθέσεις αν μια μετάβαση απορρίπτεται.

Σχετικά: [χειροκίνητες προσφορές](/el/plus/manual-quotations), [πρόγραμμα αναθέσεων](/el/plus/dispatch-schedule).
