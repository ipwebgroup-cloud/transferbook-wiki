# Διαχείριση ενημερώσεων λογισμικού

::: info Έκδοση αναφοράς
Έλεγχος πηγαίου κώδικα TransferBook+ v0.7.26. Επιβεβαιώστε εγκατεστημένη έκδοση, εταιρεία, δικαιώματα και ρυθμίσεις. Χρησιμοποιήστε εγκεκριμένα συνθετικά δεδομένα για εκπαίδευση. Δεν επιβεβαιώνεται εμπορική ενεργοποίηση.
:::

## Έλεγχος έκδοσης

1. Στο Company Settings ανοίξτε Software Updates / System Updates, εφόσον επιτρέπεται. Επιλέξτε Check for updates και ελέγξτε εγκατεστημένη και υποψήφια έκδοση.
2. Δείτε [Σημειώσεις εκδόσεων](/el/release-notes/) και [Ιστορικό αλλαγών](/el/changelog/). Νεότερη έκδοση δεν αποδεικνύει ετοιμότητα. Ελέγξτε Advanced diagnostics αν υπάρχει αβεβαιότητα διαθεσιμότητας ή συμβατότητας σχήματος.
3. Πριν από εξουσιοδοτημένη ανάπτυξη επιβεβαιώστε υπογραφή, ταυτότητα έκδοσης, ετοιμότητα migrations, αναγνωσιμότητα αντιγράφου, σχέδιο επαναφοράς και διατήρηση εταιρικών δεδομένων, domains, διαπιστευτηρίων, παρόχων και τοπικών προτύπων.
4. Ο προστατευμένος updater staging εμφανίζει Update Now μόνο όταν επιτρέπουν οι έλεγχοι. Demo και μη εγκεκριμένες εγκαταστάσεις δεν εκκινούν προστατευμένη έκδοση. Ο οδηγός δεν επιβεβαιώνει εμπορική εγκατάσταση πελάτη ή αυτόματες αναβαθμίσεις παραγωγής.

## Επιβεβαίωση εγκατάστασης

Μετά από ρητή έγκριση, υποβάλετε ενημέρωση μόνο με υποστηριζόμενη ελεγχόμενη διαδικασία. Μην επαναλαμβάνετε όσο εκκρεμεί ή εκτελείται. Επιβεβαιώστε ότι ο διακομιστής αναφέρει επαληθευμένη νέα έκδοση και κατόπιν ανανεώστε την εφαρμογή. Σε φαινομενική καθυστέρηση δείτε διαγνωστικά και ζητήστε έλεγχο αποδεικτικού εγκατάστασης και υπηρεσίας. Αίτημα, timeout ή tag GitHub δεν αποδεικνύουν επιτυχία.

Ελέγξτε έκδοση, υπηρεσία, σχήμα, διατήρηση ρυθμίσεων και εγκεκριμένες δοκιμές. Σε αποτυχία χρησιμοποιήστε εγκεκριμένη επαναφορά· ποτέ ανεξέλεγκτη αντιστροφή migration.

Δείτε [Εγκατάσταση](/el/installation/) και [Ασφάλεια](/el/security-privacy/).
