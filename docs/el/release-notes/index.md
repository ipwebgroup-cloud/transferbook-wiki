# Σημειώσεις εκδόσεων

## v0.7.11 — ελεγχόμενη δοκιμαστική έκδοση (24 Νοεμβρίου 2026)

Η έκδοση εισάγει δυνατότητες ενσωματωμένης δημοσίευσης στο Website Studio: διαχείριση φιλοξενίας, επαλήθευση HTTPS, μεταγλώττιση επιλεγμένου σχεδιασμού ιστοσελίδας, προετοιμασία ιδιωτικών αναθεωρήσεων, επαληθευμένα αντίγραφα ασφαλείας και ενημερώσεις ή επαναφορά ιστοσελίδας με εξουσιοδότηση ιδιοκτήτη. Περιλαμβάνει εξουσιοδότηση μίας χρήσης, προστασίες ανάκτησης και συμβατότητα με τον ανεξάρτητο τοπικό χώρο σχεδιασμού.

**Διαθεσιμότητα:** δημοσιευμένη έκδοση λογισμικού μόνο για ελεγχόμενη εγκατάσταση σε δοκιμαστικό περιβάλλον. Δεν αποτελεί απόδειξη ενεργής ιστοσελίδας πελάτη, ζωντανών κρατήσεων ή επεξεργασίας πληρωμών. Δεν περιλαμβάνει μεταβολές σχήματος βάσης δεδομένων ή αλλαγές σε παραγωγικές ιστοσελίδες.

## v0.7.10 — ελεγχόμενη δοκιμαστική έκδοση (24 Νοεμβρίου 2026)

Οι βελτιώσεις του Website Studio περιλαμβάνουν οπτική επεξεργασία και προεπισκόπηση συσκευών, πολύγλωσσες ιστοσελίδες αναφοράς (αγγλικά, ελληνικά, ιταλικά, γαλλικά, γερμανικά και ισπανικά), επεξεργασία ενοτήτων και ιδιοτήτων, αυτόματη τοπική αποθήκευση προσχεδίων, αντίγραφα ασφαλείας και ανάκτηση, απομόνωση προσχεδίων ανά εταιρεία, φορητά πακέτα `.tbsite.json` και `.tbtheme.json` και βελτιωμένη πλοήγηση μεταξύ Website Studio και Theme Manager.

**Διαθεσιμότητα:** δημοσιευμένη έκδοση λογισμικού μόνο για ελεγχόμενη εγκατάσταση σε δοκιμαστικό περιβάλλον. Η δημόσια δημοσίευση ιστοσελίδων, η αποθήκευση στον διακομιστή που απαιτεί τη μεταβολή σχήματος 020, οι ζωντανές πληρωμές και οι εξωτερικές διασυνδέσεις κρατήσεων δεν ενεργοποιήθηκαν από αυτή την έκδοση.

## v0.7.9 — έκδοση αναφοράς κώδικα
Τοπικό Website Studio πολλαπλών σελίδων, προεπισκόπηση συσκευών, φορητά πακέτα και προσχέδια ανά εταιρεία και τρόπο λειτουργίας. Η ενεργοποίηση βάσης δεδομένων και η δημοσίευση αποτελούν ξεχωριστά στάδια αποδοχής.

## v0.7.8 — ιστορική δοκιμαστική έκδοση
Οι καταγραφές περιγράφουν ασφαλή επανάληψη δημιουργίας κράτησης, προαιρετικό email, αποφυγή διπλοεγγραφών και ρητή συγκατάθεση μηνυμάτων. Η δοκιμαστική αποδοχή δεν πιστοποιεί εμπορική διαθεσιμότητα.

## Πολιτική εκδόσεων
Οι σημειώσεις εκδόσεων καταγράφουν δημοσιευμένες και ιστορικές εκδόσεις, όχι την τρέχουσα εγκατάσταση ή εμπορική διαθεσιμότητα. Οι υπόλοιποι οδηγοί διατηρούν την έκδοση αναφοράς τους μέχρι να ολοκληρωθεί η επαλήθευση για νεότερη έκδοση. Επιβεβαιώστε την πραγματική έκδοση και τις ενεργές δυνατότητες πριν εφαρμόσετε οδηγίες.
