# Αναφορά API κρατήσεων

::: info
Προσχέδιο βάσει πηγαίου κώδικα · v0.7.9. Επιβεβαιώστε διαθεσιμότητα και δικαιώματα στην εγκεκριμένη έκδοση.
:::

## Διαδρομές της έκδοσης αναφοράς

Όλες οι διαδρομές είναι σχετικές με το `/api/v1` και απαιτούν ταυτοποίηση χειριστή, επιλογή εταιρείας και το αντίστοιχο δικαίωμα.

| Μέθοδος και διαδρομή | Δικαίωμα |
|---|---|
| `GET /reservations` | `reservations:read` |
| `GET /reservations/:id` | `reservations:read` |
| `POST /reservations` | `reservations:write` |
| `PATCH /reservations/:id` | `reservations:write` |
| `POST /reservations/:id/quote` | `reservations:quote` |
| `POST /reservations/:id/status` | `reservations:write` |
| `POST /reservations/:id/cancel` | `reservations:cancel` |
| `POST /reservations/:id/dispatch` | `reservations:dispatch` |

## Προϋποθέσεις δημιουργίας

Η δημιουργία απαιτεί δομημένα στοιχεία πελάτη, παραλαβής, προορισμού, αριθμού επιβατών και κατηγορίας οχήματος, μεταξύ άλλων επικυρωμένων πεδίων. Απαιτούνται έγκυρη προσφορά διακομιστή και επιτρεπόμενοι πόροι εταιρείας. Το email επιβάτη είναι προαιρετικό. Ο κατάλογος δεν αποτελεί πλήρες σχήμα αιτήματος.

Η επιτυχής δημιουργία επιστρέφει HTTP 201 με την κράτηση στο `data`. Ελέγξτε την κατάσταση πριν από ανάθεση. Χρησιμοποιήστε [προστασία επανάληψης](/el/developers/idempotency.html) για κάθε πρόθεση δημιουργίας. Επιβεβαιώστε τα πλήρη σχήματα στην ακριβή εγκεκριμένη έκδοση πριν από ανάπτυξη εφαρμογής πελάτη.
