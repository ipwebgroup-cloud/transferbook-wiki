# API τιμολόγησης και τιμοκαταλόγων

::: info
Προσχέδιο βάσει πηγαίου κώδικα · v0.7.9. Επιβεβαιώστε διαθεσιμότητα και δικαιώματα στην εγκεκριμένη έκδοση.
:::

## Διεπαφή πηγαίου κώδικα

| Μέθοδος και διαδρομή (κάτω από `/api/v1`) | Δικαίωμα |
|---|---|
| `GET /tariffs` | `tariffs:read` |
| `GET /tariffs/:id` | `tariffs:read` |
| `POST /tariffs` | `tariffs:write` |
| `PATCH /tariffs/:id` | `tariffs:write` |
| `POST /tariffs/:id/status` | `tariffs:write` |
| `POST /pricing/quote` | `reservations:read` |

## Υποχρεώσεις εφαρμογής πελάτη

Ζητήστε έγκυρη προσφορά διακομιστή για τη διαδρομή και τις ρυθμίσεις. Ζητήστε νέα προσφορά όταν αλλάζουν σχετικά πεδία. Μην αντικαθιστάτε την τιμή με αυθαίρετο ποσό. Απαίτηση χειροκίνητης προσφοράς δεν σημαίνει δωρεάν κράτηση.

Η δημιουργία μπορεί να απορρίψει παρωχημένη ή αλλοιωμένη προσφορά με HTTP 409 `STALE_OR_MANIPULATED_QUOTE`. Ανανεώστε την προσφορά και ζητήστε επιβεβαίωση χειριστή πριν από νέα προσπάθεια για σκόπιμα τροποποιημένη πρόθεση κράτησης.

Δείτε [Τιμολόγηση](/el/plus/pricing.html) και [Χειροκίνητες προσφορές](/el/plus/manual-quotations.html).
