## Επιστροφές συμβάντων παρόχου

Ο κώδικας διαθέτει `POST /api/v1/webhooks/payments/:provider`. Η διαδρομή αυτή διαφέρει από το API χειριστή με bearer token. Ελέγχει την υπογραφή παρόχου στο αρχικό σώμα αιτήματος και απαιτεί εξωτερικό αναγνωριστικό συμβάντος.

| Απόκριση | Ερμηνεία |
|---|---|
| 400 | Απουσία αρχικού σώματος ή ID συμβάντος |
| 401 | Μη έγκυρη υπογραφή webhook |
| 503 | Μη ρυθμισμένο μυστικό webhook |
| 200 | Αποδοχή ή επιβεβαίωση διπλού συμβάντος |
| 500 | Αποτυχία επεξεργασίας |

Ο χειριστής καταγράφει συμβάντα με το ID παρόχου και αποτύπωμα περιεχομένου. Η επιβεβαίωση διπλού συμβάντος δεν αποτελεί δεύτερη πληρωμή. Ελέγξτε το ιστορικό συμφωνίας και την κατάσταση επεξεργασίας πριν ερμηνεύσετε την αποδοχή ως οικονομικό αποτέλεσμα.

Χρησιμοποιήστε επαληθευμένες οδηγίες υπογραφής του παρόχου και εγκεκριμένα δοκιμαστικά δεδομένα. Μην καταγράφετε μυστικά webhook ή πραγματικά στοιχεία καρτών και μην παρακάμπτετε την επαλήθευση.

Δείτε [Πάροχοι πληρωμών](/el/integrations/payment-providers.html).
