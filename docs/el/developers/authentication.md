::: info

## Σύμβαση API χειριστή

Οι προστατευμένες διαδρομές χειριστή βρίσκονται κάτω από `/api/v1`. Αποστείλετε έγκυρο bearer access token στο `Authorization` και το UUID της επιλεγμένης εταιρείας στο `X-Company-Id`. Ο διακομιστής ελέγχει ανεξάρτητα τη συμμετοχή στην εταιρεία και τα δικαιώματα. Η κεφαλίδα εταιρείας δεν παρέχει από μόνη της πρόσβαση.

Ο κώδικας χρησιμοποιεί επαλήθευση RS256 JWT. Χρησιμοποιήστε την εγκεκριμένη διαδικασία ταυτοποίησης του περιβάλλοντος. Μην ενσωματώνετε tokens χειριστών σε δημόσιες ιστοσελίδες ή widgets.

| Απόκριση | Σημασία |
|---|---|
| 401 | Απουσία ή μη έγκυρο token |
| 400 | Απουσία ή μη έγκυρη επιλογή εταιρείας |
| 403 | Άρνηση πρόσβασης εταιρείας ή δικαιώματος |
| 503 | Μη διαθέσιμη υπηρεσία εξουσιοδότησης |

Σε περίπτωση άρνησης επιλύστε το πρόβλημα πρόσβασης, αντί να αντικαταστήσετε το ID εταιρείας. Χρησιμοποιείτε μόνο συνθετικά δεδομένα στις δοκιμές.

Δείτε [Ρόλοι και δικαιώματα](/el/developers/permissions.html).

Για διαπιστευτήρια παρόχων δείτε [Κλειδιά API και ασφαλής ρύθμιση](/el/integrations/api-keys.html).
