# Ασφαλής επανάληψη δημιουργίας κράτησης

::: info
Προσχέδιο βάσει πηγαίου κώδικα · v0.7.9. Επιβεβαιώστε διαθεσιμότητα και δικαιώματα στην εγκεκριμένη έκδοση.
:::

## Κλειδί idempotency

Για `POST /api/v1/reservations`, αποστείλετε `Idempotency-Key` με 8–128 χαρακτήρες: γράμματα, ψηφία, τελεία, κάτω παύλα, άνω-κάτω τελεία ή παύλα. Δημιουργήστε μοναδικό κλειδί ανά πρόθεση κράτησης.

1. Διατηρήστε το κλειδί και το αμετάβλητο αίτημα αν η απόκριση δικτύου είναι αβέβαιη.
2. Επαναλάβετε την ίδια πρόθεση με το ίδιο κλειδί και περιεχόμενο. Μη δημιουργείτε νέα πρόθεση επειδή χάθηκε η απόκριση.
3. Αν αλλάζει σκόπιμα το αίτημα, χρησιμοποιήστε νέο κλειδί μόνο αφού διαπιστώσετε αν υπάρχει ήδη η προηγούμενη κράτηση.
4. Καταγράψτε τον κωδικό κράτησης που επιστράφηκε στη διαδικασία της εφαρμογής πελάτη.

| Απόκριση | Ερμηνεία |
|---|---|
| 201 | Νέα κράτηση ή επανάληψη αποτελέσματος |
| 201 + `X-Idempotency-Replayed: true` | Επιστροφή υπάρχοντος αποτελέσματος |
| 400 | Απουσία ή μη έγκυρο κλειδί ή κράτηση |
| 409 | Ίδιο κλειδί με διαφορετικό περιεχόμενο ή άλλη σύγκρουση |
| 503 | Μη διαθέσιμο απαιτούμενο σχήμα idempotency |

Το 503 με `RESERVATION_IDEMPOTENCY_MIGRATION_REQUIRED` δεν πρέπει να οδηγεί σε απροστάτευτη δημιουργία. Επιλύστε τη ρύθμιση έκδοσης με διαχειριστή. Το κλειδί περιορίζεται στην εταιρεία και δεν αποτελεί ταυτοποίηση.

Δείτε [API κρατήσεων](/el/developers/reservation-api.html).
