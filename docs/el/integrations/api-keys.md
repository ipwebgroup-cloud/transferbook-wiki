# Κλειδιά API και ασφαλής ρύθμιση

::: info Έκδοση αναφοράς
Έλεγχος πηγαίου κώδικα v0.7.26. Οδηγός διαχειριστή, όχι επιβεβαίωση ζωντανής σύνδεσης. Τα διαπιστευτήρια εγκατάστασης δεν δημοσιεύονται.
:::

## Αρμοδιότητες

Ο διαχειριστής εταιρείας ελέγχει ετοιμότητα και δικαιώματα. Ο εξουσιοδοτημένος διαχειριστής φιλοξενίας ρυθμίζει μυστικά διακομιστή. Ο κατάλογος διασυνδέσεων και η προβολή πληρωμών δεν αποτελούν γενικό θησαυροφυλάκιο μυστικών ούτε φόρμα εισαγωγής κλειδιών.

Το API χειριστών χρησιμοποιεί RS256 bearer token και `X-Company-Id` με ανεξάρτητο έλεγχο εταιρείας και ρόλου. Κλειδί εξωτερικού παρόχου δεν ταυτοποιεί χειριστή. Δείτε [Ταυτοποίηση](/el/developers/authentication.html).

## Διαδικασία

1. Επιβεβαιώστε εγκατεστημένη έκδοση, εταιρεία, εγκεκριμένη δυνατότητα και δοκιμαστικό λογαριασμό. Εκδώστε χωριστά κλειδιά δοκιμών και παραγωγής από την επίσημη κονσόλα παρόχου.
2. Ελέγξτε τα ακριβή ονόματα μεταβλητών της εγκατεστημένης έκδοσης. Οι οδηγοί περιέχουν ονόματα ρυθμίσεων και όχι τιμές μυστικών.
3. Αποθηκεύστε τα μυστικά σε περιορισμένο περιβάλλον υπηρεσίας ή υποστηριζόμενη ασφαλή αποθήκη, μόνο για εξουσιοδοτημένη πρόσβαση. Διατηρήστε ρυθμίσεις και δικαιώματα κατά την ενημέρωση. Ποτέ σε Git, δημόσιες ρυθμίσεις, αποθήκευση browser, στιγμιότυπα ή αρχεία υποστήριξης.
4. Οι μεταβλητές `VITE_` ενσωματώνονται στο frontend κατά το build και είναι ορατές. Μόνο δημόσιο κλειδί χάρτη με περιορισμούς ιστοτόπου και API επιτρέπεται. Ποτέ ιδιωτικά κλειδιά, κλειδιά υπογραφής JWT ή κωδικοί βάσης.
5. Εφαρμόστε την εγκεκριμένη ρύθμιση μέσω ελεγχόμενης διαδικασίας εγκατάστασης. Μην ενεργοποιείτε δημόσιες κρατήσεις ως παρενέργεια. Ελέγξτε εταιρική απομόνωση, δικαιώματα, αποτυχίες, όρια και ιστορικό με συνθετικά δεδομένα.
6. Λάβετε έγκριση ιδιοκτήτη πριν τη ζωντανή ενεργοποίηση. Καταγράψτε πάροχο, περιβάλλον, αναγνωριστικό κλειδιού (όχι τιμή), δικαιώματα, υπεύθυνο, ημερομηνία αλλαγής και αποτέλεσμα δοκιμής.

## Αλλαγή και προβλήματα

Σε παραβίαση απενεργοποιήστε τη δυνατότητα, ανακαλέστε το κλειδί στον πάροχο, αντικαταστήστε το ασφαλώς και επαναλάβετε τις δοκιμές. Μην εκτυπώνετε μυστικά. Τα 401/403 ενδέχεται να αφορούν δικαιώματα ή περιβάλλον, ενώ το 429 αφορά όριο χρήσης. Μην παρακάμπτετε ελέγχους. Η επιτυχία ελέγχου υγείας υπηρεσίας δεν αποδεικνύει σύνδεση με πάροχο.

Δείτε [Ρύθμιση API τρίτων](/el/integrations/third-party-api-setup.html) και [Ασφάλεια και ιδιωτικότητα](/el/security-privacy/).
