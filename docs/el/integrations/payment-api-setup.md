# Ρύθμιση API παρόχων πληρωμών

Έλεγχος πηγαίου κώδικα v0.7.26. Δεν επιβεβαιώνεται ενεργοποίηση παρόχου παραγωγής. Η καταγραφή μετρητών και εταιρικών τιμολογίων δεν είναι online έγκριση πληρωμής.

| Adapter | Ονόματα διαπιστευτηρίων στον κώδικα |
| --- | --- |
| PayPal | `PAYPAL_CLIENT_ID`, `PAYPAL_CLIENT_SECRET`, `PAYPAL_WEBHOOK_ID` |
| Revolut | `REVOLUT_API_KEY`, `REVOLUT_WEBHOOK_SECRET` |
| Viva | `VIVA_MERCHANT_ID`, `VIVA_API_KEY` |
| Google Pay μέσω Viva | Κλειδιά Viva και `GOOGLE_PAY_MERCHANT_ID` |
| Skrill | `SKRILL_MERCHANT_EMAIL`, `SKRILL_SECRET_WORD`· προαιρετικό `SKRILL_API_URL` |

Σημαντικό: το κείμενο ετοιμότητας Viva αναφέρει client ID/client secret και merchant source code, ενώ ο adapter χρησιμοποιεί merchant ID/API key. Απαιτείται τεχνική επαλήθευση και έλεγχος παρόχου πριν την ενεργοποίηση. Μην αντικαθιστάτε αυθαίρετα μορφές κλειδιών. Τα ονόματα δεν αποτελούν πλήρη ρύθμιση.

## Ένταξη εμπόρου

1. Ανοίξτε επαληθευμένο εμπορικό λογαριασμό στην επίσημη πύλη. Ελέγξτε διακανονισμό EUR, αγορές, κόστος, sandbox και δικαιώματα API.
2. Ο εξουσιοδοτημένος διαχειριστής εγκαθιστά δοκιμαστικά κλειδιά στον διακομιστή. Μην εισάγετε μυστικά στην προβολή ετοιμότητας εταιρείας.
3. Ελέγξτε πραγματικά endpoints και περιβάλλον checkout, επιστροφές, υπογραφή callback και οδηγίες παρόχου. Ο κώδικας διαθέτει callbacks στο `/api/v1/webhooks/payments/:provider`. Το `PAYPAL_WEBHOOK_ENVIRONMENT` αφορά έλεγχο υπογραφής και δεν εγγυάται sandbox για όλα τα endpoints. Καμία πραγματική κλήση πριν επαληθευτεί ανεξάρτητα η απομόνωση.
4. Ελέγξτε ενεργοποίηση εταιρείας, ποσό/νόμισμα, υπογραφές, διπλά συμβάντα, ακύρωση, ανάκτηση και επιστροφές με εγκεκριμένες δοκιμές. PayPal και Revolut διαθέτουν διαδρομές επαλήθευσης· μην θεωρείτε ισοδύναμη κάλυψη όλων των παρόχων. Ο ελεγμένος adapter δεν υποστηρίζει επιστροφή Skrill.
5. Συμφωνήστε την πληρωμή με στοιχεία παρόχου πριν χαρακτηριστεί εξοφλημένη. Μην επαναλαμβάνετε χρέωση επειδή έληξε ο χρόνος αιτήματος. Απαιτείται γραπτή έγκριση για παραγωγή.

Δείτε [Ετοιμότητα πληρωμών](/el/integrations/payment-providers.html) και [Webhook](/el/developers/webhook-events.html).
