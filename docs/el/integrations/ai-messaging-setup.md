# Ρύθμιση API AI, email και μηνυμάτων

Έλεγχος πηγαίου κώδικα v0.7.26. Τα παρακάτω ονόματα υπάρχουν στον κώδικα adapters. Δεν αποτελούν πλήρη σύμβαση ενεργοποίησης ή επιβεβαίωση πραγματικής αποστολής.

| Υπηρεσία | Μεταβλητές διακομιστή |
| --- | --- |
| Gemini | `GEMINI_API_KEY` |
| Resend | `RESEND_API_KEY`, `RESEND_FROM` ή `SMTP_FROM` |
| SendGrid | `SENDGRID_API_KEY`, `SMTP_FROM` |
| HTTP relay email | `SMTP_HTTP_RELAY_URL`, προαιρετικά `SMTP_PASS`, `SMTP_HOST`, ρύθμιση αποστολέα |
| Twilio SMS | `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM_NUMBER` ή `TWILIO_PHONE_NUMBER` |
| Αποστολή WhatsApp | `WHATSAPP_PHONE_NUMBER_ID`, `WHATSAPP_ACCESS_TOKEN` |
| Εισερχόμενο Meta webhook | `META_WEBHOOK_VERIFY_TOKEN`, `META_APP_SECRET` |

## Ρύθμιση και αποδοχή

1. Εκδώστε κλειδί AI από Google AI Studio ή εγκεκριμένο έργο Gemini. Ελέγξτε χρήση μοντέλου, ιδιωτικότητα και κόστος. Μόνο στον διακομιστή. Δοκιμάστε συνθετικές συνομιλίες και ανάληψη από χειριστή, χωρίς περιττά προσωπικά στοιχεία ή μη εξουσιοδοτημένες ενέργειες.
2. Για email επιλέξτε εγκεκριμένο πάροχο και επαληθεύστε αποστολέα/domain, παράδοση και αποτυχίες. Ορίστε ρητά αποστολέα. Απλό SMTP host δεν παρέχει εγγενή αποστολή SMTP σε αυτόν τον adapter· απαιτείται εγκεκριμένο HTTP relay για τη σχετική διαδρομή.
3. Για SMS απαιτούνται εγκεκριμένος αποστολέας και διαπιστευτήρια Twilio. Ελέγξτε συγκατάθεση, εξαίρεση και αποτυχίες. Για WhatsApp απαιτείται εγκεκριμένος λογαριασμός Meta Business, phone ID, access token και εγκεκριμένα πρότυπα όπου χρειάζονται.
4. Για Meta ο κώδικας διαθέτει GET επαλήθευση και υπογεγραμμένο POST στο `/api/v1/webhooks/messaging/:channel` (whatsapp, meta_messenger ή instagram). Καταχωρίστε callback μόνο μετά από έγκριση και επαλήθευση πρόσβασης. Ελέγξτε HMAC στο αρχικό σώμα αιτήματος, αντιστοίχιση λογαριασμού με εταιρεία, αποδεκτό συμβάν και προστασία διπλοεγγραφής. Μην απενεργοποιείτε υπογραφές.
5. Υπάρχει μόνιμο ιστορικό και επαναλήψεις, αλλά απαιτείται εξωτερική αποδοχή. Ελέγξτε εξαίρεση, μη διπλή παράδοση και σαφή αποτυχία. Ο οδηγός δεν εγκρίνει δημόσια λήψη κρατήσεων ή εξωτερική αποστολή.

Οι ονομασίες του καταλόγου ενδέχεται να διαφέρουν από τις πραγματικές μεταβλητές adapters. Χρησιμοποιήστε την εγκατεστημένη έκδοση και εγκεκριμένες οδηγίες. Απαγορεύεται ανεπίσημη αυτοματοποίηση WhatsApp Web.
