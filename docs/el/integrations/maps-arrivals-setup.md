# Google Maps, δρομολόγηση και API αφίξεων

Έλεγχος πηγαίου κώδικα v0.7.26. Απενεργοποιημένα εξ ορισμού. Η τοπική γεωγραφική απεικόνιση είναι ανεξάρτητη από αδειοδοτημένο οδικό χάρτη.

## Ρύθμιση Google Cloud

1. Δημιουργήστε ξεχωριστό έργο Google Cloud, εγκεκριμένη χρέωση και διαφορετικά κλειδιά ανά λειτουργία με περιορισμούς API και περιβάλλοντος.
2. Ενεργοποιήστε Maps JavaScript API και δημιουργήστε map ID για προαιρετικό χάρτη browser. Περιορίστε το κλειδί στα ακριβή εγκεκριμένα HTTPS origins. Μόνο μετά από έγκριση ρυθμίστε τις μεταβλητές build:

| Μεταβλητή | Χρήση |
| --- | --- |
| `VITE_ENABLE_GOOGLE_FLEET_MAP` | Διακόπτης χάρτη (προεπιλογή false) |
| `VITE_GOOGLE_MAPS_BROWSER_KEY` | Κλειδί browser με περιορισμούς ιστοτόπου και API |
| `VITE_GOOGLE_MAPS_MAP_ID` | Εγκεκριμένο map ID |

3. Για αναζήτηση τοποθεσίας χειριστή ενεργοποιήστε Places API (New) και Geocoding API. Ρυθμίστε μόνο στον διακομιστή το `TBPLUS_GOOGLE_LOCATION_SERVER_KEY` με περιορισμούς IP και API. Το `TBPLUS_ENABLE_GOOGLE_LOCATION_LOOKUP` παραμένει false έως έγκριση. Η αρχική αναζήτηση αφορά Ελλάδα και δεν αποθηκεύει αυτόματα διευθύνσεις παρόχου ούτε αλλάζει ναύλους.
4. Για οδικές εκτιμήσεις ενεργοποιήστε Routes API και χωριστό `TBPLUS_GOOGLE_ROUTES_SERVER_KEY` με περιορισμούς IP και API. Το `TBPLUS_ENABLE_GOOGLE_ROUTES` παραμένει false έως έλεγχο. Οι εκτιμήσεις δεν εγγυώνται άφιξη ή τιμή. Ελέγχονται φρεσκάδα GPS και εξουσιοδότηση· τα σκέλη είναι ανεξάρτητα.
5. Ρυθμίστε ποσοστώσεις και ειδοποιήσεις χρέωσης (δεν αποτελούν σκληρό όριο κόστους). Ελέγξτε CSP, αναφορά παρόχου, όρους ΕΟΧ, ιδιωτικότητα, ανάκληση δικαιωμάτων, αποτυχίες, GPS και τοπική εναλλακτική. Τα όρια εφαρμογής δεν αντικαθιστούν τις ποσοστώσεις cloud.

## Πληροφορίες αφίξεων

Η v0.7.26 υποστηρίζει μόνιμα στοιχεία μεταφορικών μέσων, χρονικά τεκμηριωμένες χειροκίνητες παρατηρήσεις, έλεγχο ειδοποιήσεων και ενημέρωση οδηγού. Εκκρεμούν αυτόματη εξωτερική παρακολούθηση πτήσεων/πλοίων, εργασίες παρασκηνίου, πλήρη όρια χρήσης και ενεργοποίηση αδειοδοτημένου χάρτη. Δεν τεκμηριώνονται εγκεκριμένα ονόματα κλειδιών ή ζωντανή διαδικασία. Ελέγξτε κάλυψη, άδειες, φρεσκάδα και κόστος πριν από μελλοντική υλοποίηση. Οι εκτιμήσεις δεν αλλάζουν αυτόματα παραλαβές ή ναύλους.

Επίσημες αναφορές πηγαίου κώδικα: [Ασφάλεια κλειδιών Maps](https://developers.google.com/maps/api-security-best-practices), [Places](https://developers.google.com/maps/documentation/places/web-service/place-autocomplete), [Geocoding](https://developers.google.com/maps/documentation/geocoding/guides-v3/requests-geocoding), [Routes](https://developers.google.com/maps/documentation/routes/compute_route_directions).
