# Εξωτερικές διασυνδέσεις ανάθεσης

::: info
Προσχέδιο βάσει πηγαίου κώδικα · v0.7.9. Επιβεβαιώστε διαθεσιμότητα και δικαιώματα στην εγκεκριμένη έκδοση.
:::

## Όριο προεπισκόπησης

Ο κώδικας περιγράφει διασυνδέσεις webhook, iCabbi, Autocab και Karhoo ως συμβάσεις sandbox. Οι προεπισκοπήσεις περιορίζονται στην εταιρεία και επιστρέφουν `transmitted: false`. Δεν αποτελούν επιβεβαίωση παραλαβής από πάροχο.

## Έλεγχος προτεινόμενης ανάθεσης

1. Επιβεβαιώστε εταιρεία και κράτηση στο εγκεκριμένο δοκιμαστικό περιβάλλον.
2. Ελέγξτε την προεπισκόπηση, τις προειδοποιήσεις, τον κωδικό κράτησης, τα στοιχεία διαδρομής και τις πληροφορίες προστασίας από διπλά αιτήματα.
3. Επιλύστε εκκρεμείς ρυθμίσεις και λάβετε έγκριση παρόχου πριν από αποστολή.
4. Συνεχίστε με την εσωτερική ανάθεση μέχρι να επαληθευτεί ξεχωριστά η ζωντανή διασύνδεση.

Αν εμφανίζεται **Not configured**, μη χρησιμοποιείτε πραγματικά στοιχεία πελατών για δοκιμή σύνδεσης.

Δείτε [Πρόγραμμα αναθέσεων](/el/plus/dispatch-schedule.html).
