## Purpose and access
Use the Reservations workspace with authorized access to your company records.

## Procedure
1. Search by reference, guest name, flight number or hotel.
2. Choose a status tab: **All**, **New**, **Confirmed**, **Assigned**, **In Transit**, **Completed**, or **Cancelled**.
3. Select the matching row to inspect details. Confirm passenger count, route, pickup time, vehicle/chauffeur and tariff total.
4. If authorized, use available editing controls on an eligible reservation. Verify the changed details and price before saving.

## Expected result
The reservation detail corresponds to the selected reference. Terminal reservations are protected from ordinary editing.

## Troubleshooting
If a booking is missing, clear the status filter and check reference and company context. If a control is unavailable, check role and status rather than bypassing the restriction. See [Reservation lifecycle](/plus/reservation-lifecycle).
