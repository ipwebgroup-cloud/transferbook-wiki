## Before you begin

Confirm the installed version, company, role, operating hub and data mode. Use only approved synthetic records for training.

## Start of shift: step by step

1. Confirm the operating hub or all-hubs scope. **Today's Timeline** opens the schedule; **Create Reservation** opens the booking form.
2. Review quotation exceptions using **Review Quote**. Confirm an approved fare before assigning a chauffeur or vehicle. Never bypass a pending quotation.
3. Review priced reservations requiring an assignment using **Review Dispatch**. Verify fleet availability, capacity and schedule conflicts. The queue is not authorization to dispatch; a new private tour may still require acceptance.
4. Review the metrics and upcoming arrivals. Arrival details come from reservations, not a live flight or ferry feed.
5. Open the relevant booking or schedule for further review. Record unresolved exceptions according to your company's procedure.

## Understand the key metrics

| Indicator | Meaning |
| --- | --- |
| Booked Tariff Value (Today) | Priced reservation value for today, not cash received. Its calculation includes a linked return scheduled today. |
| Collected / Authorized | Value of today's reservations marked paid or authorized. Authorization is not proof of settlement or cash handover. |
| Outstanding | Value indicator for positively priced, non-cancelled reservations not marked paid. It is not an exact remaining balance after partial payments. Opens the payments workspace. |
| Scheduled Today / Completed runs | Counts reservations with an outbound pickup scheduled today and those completed within that set. Not a complete count of return legs. |
| In-Transit Now / Ready Vehicles | Recorded journey and fleet availability statuses, not live GPS confirmation. |

Use the detailed payment and cash handover records for reconciliation rather than relying on dashboard totals alone.

## Verification and troubleshooting

If queues are empty, check the company, hub, permissions, date and data mode. The clear-queues message refers to the specified quotation and dispatch exceptions, not every possible company task.
