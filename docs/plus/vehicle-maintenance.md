# Vehicle maintenance windows

::: info Reference release
TransferBook+ v0.7.9 source-reviewed draft. Availability depends on the installed release, permissions and configuration; no commercial activation is asserted.
:::

Record maintenance periods so fleet planning can reflect actual vehicle availability.

## Before you begin

Use an approved workspace, confirm your company and role, and use synthetic records for training.

## Workflow

1. Open the maintenance area in Fleet management. Select the intended vehicle.
2. Choose the maintenance type (for example Scheduled Service or KTEO / Safety Inspection), start date and end date. Add relevant workshop notes.
3. Review whether the window should block dispatch as configured in the form. Save with appropriate permission, then inspect the recorded window and affected dispatch plan.

## Verification and troubleshooting

If dates or the vehicle are incorrect, correct the record using authorized controls. Do not remove a genuine safety restriction to force a booking. A saved window does not itself certify roadworthiness.
