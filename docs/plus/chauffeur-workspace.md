## Before you begin

Use an approved workspace, confirm your company and role, and use synthetic records for training.

## Workflow

1. Sign in using an authorized driver account in an approved environment. In a demonstration, a driver selector is only a simulated identity, not authentication.
2. Review assigned reservation details, pickup time and location. Use the available trip-progress action only when the actual journey reaches that step.
3. Add a concise operational note when necessary. Use the airport greeting tablet sign only for the assigned guest and avoid exposing it unnecessarily.

## Verification and troubleshooting

If a trip is missing or a progress action is unavailable, contact dispatch. Do not use another driver identity or assume a progress update transmits an external notification.
