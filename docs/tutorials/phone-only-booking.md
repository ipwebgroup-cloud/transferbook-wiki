# Create a phone-only booking

::: info
Source-reviewed training draft · TransferBook+ v0.7.9. Verify installed release, permissions and configuration. Use authorized synthetic training data; no live activation is implied.
:::

## Training scenario
A passenger requests a one-way transfer by telephone and has no email address. Use an authorized training workspace and a synthetic passenger record. A configured route, active market and suitable vehicle class are required.

## Steps
1. Open the new reservation form. Select the active operating hub and one-way service.
2. Choose two distinct catalogue locations. Set pickup date, time, passenger and luggage counts.
3. Select a class with sufficient capacity. Enter the synthetic guest name and telephone. Leave **Email (Optional)** blank.
4. Review the tariff and wait for the server-verified quote in authenticated mode. If a manual quote is required, follow the manual quotation procedure instead.
5. Submit once, then locate the resulting reference in Reservations. Verify the route, time, phone and blank email.

## Check your result
A missing email alone must not prevent booking. If the outcome is uncertain, search before creating another request. Never invent an email.

See [Create a reservation](/plus/create-reservation.html) and [Passenger information](/plus/passenger-information.html).
