# Arrange a return transfer

::: info
Source-reviewed training draft · TransferBook+ v0.7.9. Verify installed release, permissions and configuration. Use authorized synthetic training data; no live activation is implied.
:::

## Training scenario
Arrange an outbound and return transfer using synthetic data, with an active hub and configured vehicle class.

## Steps
1. Select the return service mode in the new reservation form. Confirm pickup and destination, outbound date and time.
2. Enter return date and time. The return date cannot precede the outbound date. Check the chronological order of both journeys.
3. Enter passenger and luggage counts and select a suitable class. Enter guest name and phone; email is optional.
4. Review both legs and the configured return discount, if any. A discount is not guaranteed. Confirm the verified quotation before submitting.
5. Find the booking and inspect both journeys. Review each leg in dispatch before allocating resources.

## Check your result
Both journey schedules must match the request. Do not assume an outbound allocation guarantees an available driver for the return.
