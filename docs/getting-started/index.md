# Getting Started

Welcome to TransferBook+, the transportation operating platform for reservations, dispatch and commercial management.

## Prepare your workspace

1. Confirm the installed software release and your authorized access.
2. Check the operating hub, available vehicle classes and configured locations.
3. Use an approved demonstration or staging environment for training. Use synthetic passenger records in examples.

Available functionality depends on the installed release, permissions and enabled integrations. This local documentation is a draft pending operational review.
