# Administrator quick start

::: info Reference release
Operational guidance reviewed against v0.7.26. Verify the installed release, permissions and approved scope. Training uses authorized synthetic data; this guide does not authorize commercial activation.
:::

## First administrator session

1. Obtain the approved deployment address and individual credentials from the authorized administrator. Verify HTTPS, company selection and role.
2. Review [company onboarding](/getting-started/company-onboarding.html). Complete legal identity, operating markets, local time zones, location catalog, fleet and approved pricing.
3. Request backend provisioning of each staff account; do not share administrator credentials. Match real driver accounts to authorized driver records and test restricted access.
4. Review payment recording, booking channels, notification templates and branding. Do not enable a public channel or external provider merely to complete the checklist.
5. In an approved synthetic training environment, create the [first reservation](/getting-started/first-reservation.html), test dispatch, driver access and reconciliation. Record failures before proceeding.
6. Review [go-live acceptance](/getting-started/go-live-checklist.html) with the business and technical owners. Obtain approval for the specific scope; unaccepted features remain unavailable.

## Daily administration

Review access changes, failed operations, upcoming assignments, financial exceptions and provider readiness. Confirm installed release and review [Release Notes](/release-notes/) before requesting updates. Use the [Update Manager guide](/plus/software-update-manager.html); no automatic commercial update authorization is implied.
