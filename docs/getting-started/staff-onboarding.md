# Staff and chauffeur onboarding checklist

::: info Reference release
Operational guidance reviewed against v0.7.26. Verify the installed release, permissions and approved scope. Training uses authorized synthetic data; this guide does not authorize commercial activation.
:::

## Before the first shift

- [ ] Verify approved identity, duties, company and required access.
- [ ] Request individual backend account and minimum role from the authorized administrator.
- [ ] For a chauffeur, create or review the driver record, approved vehicle/roster and account association.
- [ ] Deliver credentials through a secure channel; require strong unique passwords.
- [ ] Test actual role sign-in, company scope, logout and denied actions using synthetic records.
- [ ] Test mobile browser, connectivity, assignment visibility, independent outbound/return progress and arrival brief where available.
- [ ] Explain passenger privacy, cash collection and physical handover procedures.
- [ ] Test explicit on-duty GPS opt-in only where approved; physical mobile GPS acceptance remains separate.
- [ ] Provide shift escalation and support contacts; record training acceptance.

The checklist is a manual operational aid, not an account creation form or automatically saved approval. Public job applications are not account provisioning. On departure, request backend revocation of access and active sessions, verify denial, and preserve operational records.
