# Pages, sections and navigation

::: info Reference release — source-reviewed draft
TransferBook+ v0.7.9 source baseline. Availability depends on installed release, permissions and configuration. Live publication is not established by this guide.
:::

## Purpose
Build the page tree and reusable content blocks of a website. Work in an authorized draft with a valid design system.

## Organize pages
1. Select the website in the structure panel.
2. Use the page tree to add, duplicate or reorder pages. The root route `/` is protected.
3. Choose a page, then add a reusable section preset, such as a booking panel, fleet showcase or FAQ.
4. Select a section in the canvas or outline. Adjust its variant, spacing, alignment and device visibility in the inspector.
5. Review header and footer navigation and follow each link in the preview.

## Expected result
A multi-page draft with navigable pages and reusable sections. The reference blueprint supports `/`, `/transfers`, `/fleet`, `/tours` and `/contact`, as well as user-created pages.

## Troubleshooting
If a route is rejected, check for duplicate or unsafe slugs. Do not bypass validation. Hiding a section on a device does not delete its content. Review [responsive previews](./responsive-preview.md).
