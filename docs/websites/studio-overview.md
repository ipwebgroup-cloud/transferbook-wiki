## Purpose and access
Website Studio is the multi-page visual editor in TransferBook+. In the reference source, open **Channels & Governance → Website Studio**, or select Website Studio from **Settings → Website & Themes**. Use an authorized company context; the standalone design kit is a separate local workspace.

## Understand the three panels
1. The left panel manages websites, markets, pages, sections and navigation.
2. The central canvas renders the selected page and supports selecting and arranging sections.
3. The right inspector exposes block settings, Page & SEO, Design, Brand & Markets and History.

## Begin safely
Select a synthetic reference website or a permitted draft. Confirm the intended company, then select a page and a preview device. The built-in reference sites are examples, not verified operational customer websites.

## Expected result and troubleshooting
A draft renders in the canvas without publishing a website. If no company context is available, do not bypass the warning; return to the authorized workspace. See [draft storage](./draft-storage.md) before changing browser or company.

## Editor refinements in v0.7.10
**Status: source-reviewed staging release.** In a compatible Website Studio workspace:

1. Select Edit mode to arrange sections; switch to Preview to inspect the design without editor selection outlines and floating controls.
2. Search the section preset library and insert a preset after the selected section when appropriate.
3. Review the header and footer menus, header CTA and locale switcher; verify navigation in the canvas.
4. Use `Ctrl/Cmd+S` to save a draft, `Ctrl/Cmd+Z` to undo, `Ctrl/Cmd+Shift+Z` or `Ctrl+Y` to redo, and `Esc` to leave preview or clear selection. Confirm that the save succeeded.
5. Review desktop, tablet, mobile and 320 px narrow-mobile layouts, including the mobile menu and booking controls.

The canvas is a preview, not proof of a live website. The standalone design kit has compatible editor refinements; its installed version must be checked independently. See [local drafts](./draft-storage.md).
